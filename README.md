# Генератор шаблону курсової роботи (ДСТУ)

Цей проект містить скрипт для генерації шаблону курсової роботи з форматуванням згідно з вимогами ДСТУ.

## Вимоги

- Python 3
- Бібліотека `python-docx`

Встановлення залежностей:
```bash
pip install -r requirements.txt
```

## Використання

Запустіть скрипт:
```bash
python generate_docx.py
```

Згенерований файл `Курсова_робота.docx` буде збережено в поточній директорії. Він містить налаштовані поля, шрифти, відступи та заголовки розділів відповідно до вашого завдання. Оскільки автоматична генерація 30 сторінок унікального інженерного тексту не підтримується, текст розширено для демонстрації форматування, і вам потрібно буде замінити його на ваш власний.
