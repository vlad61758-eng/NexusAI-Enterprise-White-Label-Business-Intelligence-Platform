# Архітектура та Технологічний стек (2026 AI Premium Store)

## Мета
Створити ультрашвидкий, безпечний та конверсійний інтернет-магазин для продажу преміальних B2B цифрових продуктів (AI боти, мікро-SaaS, скрипти) з акцентом на автоматизацію, Web3-платежі та миттєву доставку.

## Технологічний стек (Наш вибір)

*   **Фреймворк:** **Next.js 14+ (App Router)**. Забезпечує найкращий баланс між продуктивністю (Server Components) та динамічністю (Client Components). Дозволяє швидко рендерити сторінки (SEO важливо для каталогу) та безпечно приховувати API ключі на сервері.
*   **Стилізація:** **Tailwind CSS + Framer Motion + Lucide React**. Tailwind дозволяє швидко створювати складні інтерфейси в стилі "Glassmorphism" та "Dark Mode". Framer Motion відповідає за плавні, дорогі анімації, що підкреслюють преміальність продуктів. Lucide React надає гарні векторні іконки.
*   **Мова програмування:** **TypeScript**. Гарантує типобезпеку, зменшує кількість помилок під час розробки, особливо при роботі з каталогом продуктів та платіжними шлюзами.
*   **База даних (Планується):** **PostgreSQL + Prisma ORM (або Supabase)**. Для зберігання історії транзакцій, генерації унікальних посилань на завантаження та управління користувачами (якщо буде додано особистий кабінет). Зараз використовується mock-база в `src/lib/products.ts`.
*   **Платежі:** **Web3 / Crypto (MetaMask, Coinbase Commerce, NOWPayments)**. Основний метод оплати для цільової аудиторії (USDT/ETH). Забезпечує миттєві транзакції без географічних обмежень. Фіат (Stripe/Payoneer) може бути доданий як резерв.
*   **Доставка контенту (Хостинг файлів):** **AWS S3 / Cloudflare R2**. Архів з продуктом (ZIP без `__pycache__` тощо) та інструкціями лежить у приватному бакеті. Після оплати генерується тимчасове (signed) посилання для завантаження.
*   **Деплой:** **Vercel**. Найкраща інтеграція з Next.js, Edge Network для швидкості по всьому світу.

## Структура проєкту

```text
ai-store/
├── src/
│   ├── app/                    # Next.js App Router (Сторінки)
│   │   ├── page.tsx            # Головна сторінка (Hero, Переваги, Сітка товарів)
│   │   ├── layout.tsx          # Глобальний layout
│   │   └── product/
│   │       └── [id]/
│   │           └── page.tsx    # Динамічна сторінка конкретного товару
│   ├── components/             # Перевикористовувані UI компоненти
│   │   └── CryptoPayment.tsx   # Компонент платіжного флоу (Mock Web3)
│   └── lib/                    # Логіка, утиліти, константи
│       └── products.ts         # База даних (каталог 10 товарів)
├── public/                     # Статичні файли (картинки, фавіконки)
├── tailwind.config.ts          # Налаштування стилів та дизайн-системи
└── package.json                # Залежності
```

## User Flow (Шлях клієнта)

1.  **Залучення (Головна сторінка):** Відвідувач потрапляє на головну сторінку, бачить потужний ціннісний заголовок, преміальний "темний" дизайн з неоновими акцентами. Він переглядає сітку з 10 AI-продуктів.
2.  **Вибір (Сторінка товару):** Клієнт клікає на товар (наприклад, "AI LeadGen Bot"). Він бачить детальну сторінку:
    *   Відео-демонстрацію "Як це працює".
    *   Скріншоти інтерфейсу.
    *   Блок "Що всередині" (Core Features).
    *   Коротка інструкція із запуску.
3.  **Оплата (1-2 кліки):** Клієнт натискає велику кнопку "Pay with Crypto". З'являється Web3-гаманець (або модальне вікно вибору мережі). Клієнт підтверджує транзакцію в USDT/ETH. *Ніяких довгих реєстрацій.*
4.  **Миттєва доставка:** Відразу після підтвердження транзакції в блокчейні (або через webhook платіжного шлюзу), система автоматично перенаправляє клієнта на сторінку успіху або одразу починає завантаження ZIP-архіву з програмою та детальним `README.md` (з відеоінструкцією).

## Чому такий підхід?
Ця архітектура орієнтована на продаж **High-Ticket B2B рішень**. Вона мінімізує тертя при покупці (немає реєстрації, оплата в крипті) та викликає довіру за рахунок ультрасучасного UI (Next.js + Tailwind + Framer Motion), який виглядає дорого і професійно.
